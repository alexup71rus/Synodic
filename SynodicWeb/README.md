# SynodicWeb

Фронтенд Synodic — сайта для совместного просмотра видео вдвоём.

Вставляете ссылку на видео (YouTube, Rutube или публичное VK Видео),
создаёте комнату, отправляете напарнику код или ссылку — дальше пауза,
перемотка и продолжение синхронизируются между вами. Скорость общая там,
где официальный API плеера позволяет ею управлять (YouTube и Rutube).

## Как устроено

Чистый статический сайт без сборщика: HTML + CSS + обычный JS.

- `index.html` — единственная страница: стартовый экран и комната.
- `css/main.css` — стилистика перенесена из расширения Synodic: тёмная
  «ночная» тема, луна, тёплое золото, сериные заголовки.
- `js/links.js` — разбор ссылок YouTube/Rutube/VK (watch, share, embed,
  shorts, приватные видео Rutube с параметром `p`).
- `js/net.js` — REST-клиент и WebSocket-соединение с автопереподключением.
- `js/players.js` — адаптеры плееров с общим интерфейсом:
  YouTube IFrame API, Rutube postMessage API и официальный VK Video JS API.
  Для публичной ссылки VK сервер без пользовательского токена получает
  официальный embed через `video.getOembed`.
- `js/sync.js` — движок синхронизации: эхо-защита (окно после применённой
  команды), экстраполяция ожидаемого времени, коррекция дрейфа,
  «готовность» (жест пользователя решает проблему autoplay).
- `js/protocol.js` — константы сообщений; держать синхронно с
  `SynodicServe/src/rooms.js`.

Видео нигде не проксируется: страница встраивает официальный embed-плеер
источника, по сети синхронизируется только состояние просмотра.

## Разработка

Статику отдаёт SynodicServe (в дев-режиме берёт `../SynodicWeb`):

    cd ../SynodicServe && npm install && npm run dev
    open http://localhost:8787

Локальная проверка в одиночку: две вкладки с одним и тем же видео,
в одной — создать комнату, в другой — войти по коду.

## Деплой

Фронтенд деплоится скриптом SynodicServe (`scripts/deploy.sh`): файлы
уезжают на сервер в `public/` рядом с бэкендом. Отдельного деплоя нет.

## Известные ограничения

- реклама в плеерах не синхронизируется: если у одного участника
  включён блокировщик рекламы, ролики сместят просмотр (лечится паузой);
- перемотка определяется по потоку времени — очень короткие (менее ~1 c)
  скачки вперёд могут не синхронизироваться сразу, добьётся heartbeat;
- комната без авторизации: кто знает код — тот и участник.

# SynodicExt

Браузерное расширение Synodic — совместный удалённый просмотр видео.

Расширение работает на странице с видео: находит HTML5-`<video>`, отслеживает
`play` / `pause` / `seek` / смену скорости и применяет события, пришедшие от
второго участника через сервер [SynodicServe](../SynodicServe). Само видео
не передаётся — синхронизируется только состояние просмотра.

Если на странице несколько роликов, расширение выбирает крупнейшее видимое
видео, игнорирует технические микровидео и распространённые рекламные/promo-
контейнеры, а также перепроверяет выбор при динамическом изменении страницы.
Уже открытую до установки расширения вкладку оно подключает само — ручная
перезагрузка страницы не требуется.

Для YouTube, Rutube и публичных VK Видео можно смотреть смешанной парой: один участник остаётся
на исходной странице с расширением, второй входит по тому же коду на сайте
Synodic. Расширение передаст серверу только безопасный идентификатор ролика,
а не адрес произвольной страницы. На других сайтах расширение нужно обоим.

## Структура

- `manifest.json` — MV3; content script на всех http/https-страницах, включая
  cross-origin, `about:blank` и `blob:` iframe
- `src/content/content.js` — ядро синхронизации: поиск `<video>`, локальные события, применение чужих
- `src/background/service-worker.js` — WebSocket к серверу, пересылка событий
- `src/popup/` — UI: комната, выбор вкладки и одновременный старт после готовности обоих
- `src/shared/protocol.js` — общие константы протокола для всех контекстов
- `.env.example` — публичный production-адрес сервера по умолчанию
- `scripts/configure.mjs` — генерация `src/shared/config.js` с необязательными override
- `design/icon.svg` — мастер знака; готовые PNG-размеры лежат в `icons/`

## Запуск (разработка)

1. Использовать Chrome 116 или новее.
2. Поднять SynodicServe — локально (`npm run dev`) или на сервере (`scripts/deploy.sh`).
3. При необходимости создать `.env.local` с локальным адресом, например
   `SYNODIC_SERVER_URL=http://localhost:8787`. Этот файл не попадёт в Git.
4. Выполнить `scripts/package.sh`: команда обновит публичную конфигурацию и соберёт ZIP и unpacked-версию.
5. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → выбрать `dist/synodic-ext-0.3.2-unpacked`.
6. «Создать комнату» → скопировать и передать код комнаты напарнику.
7. Когда оба подключились и видео найдено, каждый нажимает «Смотреть вместе».

Комната остаётся привязана к выбранной вкладке, даже если пользователь
переключается между другими. Чтобы перенести её, нужно явно нажать
«Выбрать эту вкладку» в popup — предыдущая вкладка после этого отключается.

Технический smoke-тест маршрутизации service worker запускается без Chrome и
внешних зависимостей:

    node scripts/smoke.mjs

Он проверяет runtime-подключение уже открытой вкладки, привязку к одному
document, явную смену вкладки, выбор видимого видео (включая Shadow DOM),
передачу YouTube/Rutube/VK-источника на сайт, готовность обоих, media-события,
первоначальный снапшот хозяина, навигацию и восстановление соединения.

Локально можно тестировать в одиночку в двух независимых профилях Chrome или
двух браузерах с отдельно загруженным расширением: в одном создать комнату,
во втором — войти по коду. Две вкладки одного профиля не подходят, потому что
они используют общий service worker и одну активную комнату.

## Пакет расширения

Расширение не требует сборщика или зависимостей. Команда ниже берёт production-
адрес SynodicServe из `.env.example` (с необязательным локальным
переопределением в `.env` или `.env.local`), генерирует публичный
`src/shared/config.js`, создаёт ZIP с `manifest.json` в корне и рядом готовит
идентичную распакованную папку:

    scripts/package.sh

Оба артефакта появятся в `dist/`; распакованную папку можно сразу загрузить в
Chrome, а ZIP оставить для релиза.

## Известные ограничения MVP

- Если браузер всё же отклонит запуск после «Смотреть вместе», popup предложит
  повторить попытку или один раз нажать Play прямо на видео.
- Комната привязывается к вкладке, в которой её создали или открыли; другие
  вкладки с видео расширение не трогает. Внутри выбранной вкладки команды
  получает только один frame с крупнейшим видимым видео.
- Во время воспроизведения серверный heartbeat раз в 3 с корректирует дрейф больше 0,5 с;
  меньшее расхождение намеренно не трогает видео.
- После обрыва сети расширение переподключается к комнате и принимает последний
  серверный снапшот. Действия, сделанные офлайн, задним числом не отправляются.
- Активная комната переживает перезапуск service worker, но не перезапуск Chrome.
